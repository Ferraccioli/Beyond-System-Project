# Espaçamento

Base de **4px**. Os 11 tokens do Beyond System mapeiam diretamente para as classes de espaçamento do Tailwind — `p-`, `m-`, `gap-`, `space-` e afins.

---

## Além de `p-10`

Para valores maiores, use as classes Tailwind padrão: `p-12` (48px), `p-14` (56px), `p-16` (64px), `p-20` (80px), `p-24` (96px). Não é necessário adicionar tokens customizados para esses valores.
