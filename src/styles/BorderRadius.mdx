# Border Radius

Os tokens de raio do Beyond System mapeiam 1:1 com as classes `rounded-*` do Tailwind v4. O token `--radius-xs` (2px) e `--radius-4xl` (32px) são expostos como tokens customizados; os demais usam os defaults do Tailwind.

---

## Escala visual

<div style={{ fontFamily: 'Poppins, sans-serif', display: 'flex', flexWrap: 'wrap', gap: 20, padding: '8px 0' }}>
  {[
    { cls: 'rounded-none', token: '—',            px: '0px',    r: 0 },
    { cls: 'rounded-xs',   token: '--radius-xs',  px: '2px',    r: 2 },
    { cls: 'rounded',      token: '--radius-sm',  px: '4px',    r: 4 },
    { cls: 'rounded-md',   token: '--radius-md',  px: '6px',    r: 6 },
    { cls: 'rounded-lg',   token: '--radius-lg',  px: '8px',    r: 8 },
    { cls: 'rounded-xl',   token: '--radius-xl',  px: '12px',   r: 12 },
    { cls: 'rounded-2xl',  token: '--radius-2xl', px: '16px',   r: 16 },
    { cls: 'rounded-3xl',  token: '--radius-3xl', px: '24px',   r: 24 },
    { cls: 'rounded-4xl',  token: '--radius-4xl', px: '32px',   r: 32 },
    { cls: 'rounded-full', token: '--radius-full','px': '9999px', r: 9999 },
  ].map(({ cls, token, px, r }) => (
    <div key={cls} style={{ display: 'flex', flexDirection: 'column', alignItems: 'center', gap: 8 }}>
      <div
        style={{
          width: 64,
          height: 64,
          backgroundColor: '#ecf1ff',
          border: '1.5px solid #4378ff',
          borderRadius: Math.min(r, 32),
        }}
      />
      <div style={{ textAlign: 'center' }}>
        <div style={{ fontSize: 11, color: '#4378ff', fontWeight: 500 }}>{cls}</div>
        <div style={{ fontSize: 10, color: '#696c71' }}>{px}</div>
      </div>
    </div>
  ))}
</div>
