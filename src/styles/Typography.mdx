# Tipografia

O Beyond System usa **Poppins** como fonte única, exposta via `font-sans` e `font-display` no Tailwind. A escala de tamanhos espelha as classes utilitárias do Tailwind, com dois tokens extras (`text-3xs` e `text-2xs`) para uso em labels e badges compactos.

## Pesos

Poppins carrega todos os pesos (100–900). Use apenas os abaixo para manter consistência.

## Padrões de combinação

```html
<!-- Título de página -->
<h1 class="font-sans text-2xl font-bold text-default">Título</h1>

<!-- Subtítulo de seção -->
<h2 class="font-sans text-xl font-semibold text-default">Seção</h2>

<!-- Corpo principal -->
<p class="font-sans text-base font-normal text-body">Parágrafo</p>

<!-- Corpo secundário -->
<p class="font-sans text-sm font-normal text-body">Texto secundário</p>

<!-- Label de campo -->
<label class="font-sans text-xs font-medium text-default">Rótulo</label>

<!-- Helper / caption -->
<span class="font-sans text-xs font-normal text-muted">Texto auxiliar</span>

<!-- Badge / tag compacta -->
<span class="font-sans text-2xs font-medium text-body">Badge</span>
```
